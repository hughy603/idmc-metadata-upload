# Keyboard Shortcuts

This guide lists all available keyboard shortcuts in the IDMC Metadata Upload application.

## Global Shortcuts

| Action | Windows/Linux | Mac | Description |
|--------|--------------|-----|-------------|
| Open File | Ctrl + O | ⌘ + O | Open file selector |
| Save | Ctrl + S | ⌘ + S | Save current changes |
| Submit | Ctrl + Enter | ⌘ + Enter | Submit current selection |
| Help | F1 | F1 | Open help documentation |
| Search | Ctrl + F | ⌘ + F | Search in current view |

## File Upload

| Action | Windows/Linux | Mac | Description |
|--------|--------------|-----|-------------|
| Upload File | Ctrl + U | ⌘ + U | Open file upload dialog |
| Clear Selection | Esc | Esc | Clear file selection |
| Validate File | Ctrl + V | ⌘ + V | Validate current file |
| Cancel Upload | Ctrl + X | ⌘ + X | Cancel ongoing upload |

## Table Navigation

| Action | Windows/Linux | Mac | Description |
|--------|--------------|-----|-------------|
| Select All | Ctrl + A | ⌘ + A | Select all rows |
| Deselect All | Ctrl + D | ⌘ + D | Deselect all rows |
| Next Row | ↓ | ↓ | Move to next row |
| Previous Row | ↑ | ↑ | Move to previous row |
| First Row | Home | Fn + ← | Jump to first row |
| Last Row | End | Fn + → | Jump to last row |
| Page Down | PgDn | Fn + ↓ | Move down one page |
| Page Up | PgUp | Fn + ↑ | Move up one page |

## Row Actions

| Action | Windows/Linux | Mac | Description |
|--------|--------------|-----|-------------|
| Process Row | Ctrl + P | ⌘ + P | Process selected row |
| Retry Failed | Ctrl + R | ⌘ + R | Retry failed rows |
| Skip Row | Ctrl + K | ⌘ + K | Skip selected row |
| Edit Row | Ctrl + E | ⌘ + E | Edit selected row |
| Delete Row | Ctrl + Del | ⌘ + Backspace | Delete selected row |

## Batch Operations

| Action | Windows/Linux | Mac | Description |
|--------|--------------|-----|-------------|
| Process Selected | Ctrl + Shift + P | ⌘ + Shift + P | Process selected rows |
| Skip Selected | Ctrl + Shift + K | ⌘ + Shift + K | Skip selected rows |
| Delete Selected | Ctrl + Shift + D | ⌘ + Shift + D | Delete selected rows |

## View Controls

| Action | Windows/Linux | Mac | Description |
|--------|--------------|-----|-------------|
| Zoom In | Ctrl + + | ⌘ + + | Increase table size |
| Zoom Out | Ctrl + - | ⌘ + - | Decrease table size |
| Reset Zoom | Ctrl + 0 | ⌘ + 0 | Reset table size |
| Toggle Details | Ctrl + I | ⌘ + I | Show/hide row details |
| Refresh View | F5 | ⌘ + R | Refresh current view |

## Column Management

| Action | Windows/Linux | Mac | Description |
|--------|--------------|-----|-------------|
| Hide Column | Alt + H | ⌥ + H | Hide selected column |
| Show All Columns | Alt + S | ⌥ + S | Show all columns |
| Reset Columns | Alt + R | ⌥ + R | Reset column layout |
| Resize Columns | Alt + F | ⌥ + F | Auto-fit columns |

## Filter and Sort

| Action | Windows/Linux | Mac | Description |
|--------|--------------|-----|-------------|
| Toggle Filters | Ctrl + Shift + F | ⌘ + Shift + F | Show/hide filters |
| Clear Filters | Ctrl + Shift + C | ⌘ + Shift + C | Clear all filters |
| Sort Ascending | Alt + ↑ | ⌥ + ↑ | Sort column ascending |
| Sort Descending | Alt + ↓ | ⌥ + ↓ | Sort column descending |

## Status Management

| Action | Windows/Linux | Mac | Description |
|--------|--------------|-----|-------------|
| Show Errors | Alt + E | ⌥ + E | Show only errors |
| Show Completed | Alt + C | ⌥ + C | Show only completed |
| Show Pending | Alt + P | ⌥ + P | Show only pending |
| Show All | Alt + A | ⌥ + A | Show all statuses |

## Notes

- Modifier Key Symbols:
  - Windows/Linux: Ctrl (Control), Alt (Alt), Shift (Shift)
  - Mac: ⌘ (Command), ⌥ (Option), ⇧ (Shift)
- Some shortcuts may be intercepted by your browser or operating system
- Shortcuts can be customized in the application settings
